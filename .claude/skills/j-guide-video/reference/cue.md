# キュー（工程の動きの書き方）

工程の動きは、Swift のコードではなく **キュー**（`cues/<Visual>.cue`）で書く。1 行 = 1 つの時刻に起きること。道具・画面の描き方と名前は、動画ごとに 1 回だけ **binding**（`visuals/bind.swift`）に Swift で書き、どの工程のキューからも名前で指す。

- キューは実行時に読む。直してもビルドし直さないので、`jgv check` / `jgv snapshots` がすぐ（約 1 秒）終わる
- 工程の始まりの状態は前の工程の終わりから引き継ぐ（`init <前の工程`）。工程の境目がずれない
- 確かめは文字で返る `jgv check`（手の時刻表・状態・問題）を先に使い、画像は最後に見る

```
procedure.md ─(jgv md2script --stubs visuals)→ script.json・cues/*.cue・visuals/<Visual>.swift・visuals/bind.swift
  ─(jgv tts)→ 音声・timeline ─(bind.swift と cues/*.cue を書く)→ jgv check ⇄ 直す → jgv dev ⇄ 直す → jgv render
```

## ファイル

| ファイル | 中身 | 書く人 |
|---|---|---|
| `cues/<Visual>.cue` | 工程の動き。雛形の先頭に `# 行.句 文` の注釈（時刻の番号）がある | Claude |
| `visuals/bind.swift` | `let BIND = CueBinding(...)`。値・物・点・置き場所の名前と、描き方 | Claude（動画ごとに 1 回） |
| `visuals/<Visual>.swift` | `func <Visual>(_ props: Props) { CueScene("<Visual>", BIND) }` の 1 行 | `md2script --stubs` が作る。触らない |
| `visuals/props.swift` など | 新しく描く道具（[prop-style.md](prop-style.md)） | 必要なときだけ |

## 文法

```
# 注釈 (行末まで)
init [<前の工程] 値=… 物@置き場所 …
<時刻> 命令;命令;…
```

**時刻**: `L.P`（行 L の句 P の読み始め。行・句は 0 始まりで、雛形の注釈の番号）か `end`（工程の終わり）。`+秒` / `-秒` でずらす（`0.2+.45`、`1.1-.1`、`end-.5`）。

| 命令 | 意味 |
|---|---|
| `H>点[~秒]` | 右手（指・カーソル）が **その時刻に点へ着く**（既定 0.4 秒かけて動く）。着いた後は点が動いても付いていく（扉の取っ手・運んでいる物の縁） |
| `C>点[~秒]` | 拡大カードの中の手（袖の腕）。同じく **着く時刻** |
| `P 点` | 右手（指）で点を押す。着いてから 0.14 秒の間、値 `pressed` が点の名前になる |
| `値=数[~秒]` | 値をその時刻から変える（既定は一瞬）。`値=数@時刻` はその時刻まで |
| `値=文字` | 文字の値にする（`mw.disp=600W`。`値=` で空）。文字の値は一瞬で変わり、末尾の `~数` / `@時刻` は誤りになる（文字の末尾に「~数」を出すときは全角の `〜` を使う） |
| `値=cd A B@時刻` | 文字の値を A から B まで数え下ろす（`2:00` → `0:00`） |
| `値=wave 幅 周期@時刻` | 値に揺れを足す（`H.dx` `H.dy` `C.dx` `C.dy` で手を揺らす・こする。円を描くなら dx と dy を周期の 1/4 ずらす） |
| `物@置き場所[~秒]` | 物を置き場所へ動かす（既定 0.6 秒、途中は弧を描く）。`物.x` `物.y` `物.s` が変わる |
| `drop 物[~高さ]` | 物が落ちてきて置かれる（`物.vis` が 1 になる。`init` で `物.vis=0` にしておく） |
| `card ラベル@時刻\|ラベル@時刻\|…` | 拡大カードを出し、小手順ラベルを切り替える。命令の時刻がカードの開き始め（ふつう `0.0-.4`） |
| `shrink 点[~秒]` | 拡大カードを点へ縮めて消す |
| `notes 文字@時刻\|…` | 右側のポイントメモ（画面操作型。位置は点 `notes`、既定 (1000, 270)。幅は 820 で決まっているので、横型では左端を x 1000 より右にできない。スマホ・ブラウザの枠はメモと重ならないよう右端を x 980 ほどまでにする） |
| `parts 記号:名前:数@時刻\|…` | 部品リスト（組み立て説明書型。その時刻に行が光る。位置は点 `parts`）。工程ごとに書く（引き継がない）。名前を訳すときは `$キー`（`:` で区切るので `$キー:既定` は使えない。台本の `strings` に訳を書く）。見出しは `strings` の `parts.title`、無ければ言語の既定（日本語「部品」、英語「Parts」など） |
| `say 点 文字[@時刻]` | 注釈（`@時刻` で消える。無ければ工程の終わりまで） |
| `timer 点 文字@時刻` | 円弧タイマー（その時刻で一周） |
| `pulse 点[@時刻]` / `steam 点[@時刻]` / `sparkle 点[@時刻]` / `check 点` | 波紋・湯気・きらめき・完了のチェック |

**点**: binding の点の名前、`rest`（定位置）、`gesture`（人物が指し示す位置）、`c.away`（カードの外）、`c.sleeve`（袖の腕の付け根。カードの右下の外）、`名前+dx,dy`（ずらす）、`(x,y)`（画面座標）。点の名前が `c.` で始まる注釈・湯気などは拡大カードの中に描く。

**書けない文字**: `#`（行末までを注釈にする）と `;`（命令の区切り）は、注釈・ラベルの文字にも書けない。`|` は `card` `notes` `parts` の区切り。

**文字**（`say` `timer` `card` `notes`）: `$キー:既定の文`（例 `say mw.top $heat.chin:チン！`）と書くと、台本の `strings[キー]` を使う。多言語版（[multilang.md](multilang.md)）は `script.<言語>.json` の `strings` に訳を入れるだけで切り替わる。1 言語だけの動画なら直書きでよい。

**kit が使う・入れる値**: `smile`（人物の笑顔 0〜1）、`card.enter=0` / `card.exit=0`（init に書くと、カードを開いたまま前後の工程とつなぐ）、`H.x` `H.y` `C.x` `C.y`（手の位置）、`pressed`（押している点）。

### 時刻の決まり（いちばん間違えやすい）

- **手（`H>` `C>` `P`）は「着く時刻」、ほかはすべて「始まる時刻」**
- 手の動きに値の変化を合わせるときは、値の時刻を手の動きの長さだけ前にする。指でスワイプしながら数字を回すなら:

  ```
  0.1 H>hour+0,-60~.5     # 0.1 に着く (0.1-.5 から動く)
  0.1-.5 hour=7~.5        # 同じ 0.1-.5 から 0.5 秒で変える
  ```

- 手で物を運ぶ: 手を物の縁へ着けてから物を動かす。手は縁に付いていく
  ```
  1.1+.7 H>dish.gripL~.4
  1.1+.77 dish@PLATE~.5
  ```
- 手でつまんだ物を動かす（ラップをはがす・扉を開ける）: 動かし終わる前に手を離さない（`jgv check` が「まだ動いている」と出す）
- 片付ける・手を戻すなどの「終わり」の動きは、工程の終わりの 0.5 秒前までに終える。右手は最後に自動で定位置へ戻る。**戻り始めるのは終わりの 1.05 秒前**なので、右手 `H` が持っている点の動きと、最後の `H>` の到着はそれまでに終える（多言語版で読み上げの長さが変わっても通るよう、終わりの動きは `end-秒` で書く）
- 数は 10 進の小数だけ（`1`・`-.5`・`0.35`。`1e3`・`inf` は文字の値になる）。区切りはスペースかタブ

## binding（`visuals/bind.swift`）

```swift
import JGVKit

let BIND = CueBinding(
  keys: ["mw.open", "mw.on", "mw.disp", "rice.heat"],          // キューで使う値の名前 (物の値・H. C. は書かなくてよい)
  objects: ["dish", "rice"],                                   // 動かす物 (物.x 物.y 物.s 物.vis 物.dy)
  points: [                                                    // 手を伸ばす・注釈を出す点 (状態 s から計算してよい)
    "mw.handle": { s in mwHandle(s["mw.open"]) },
    "dish.gripL": { s in let d = s.obj("dish"); return Pt(d.x - 100 * d.s, d.y - 14 * d.s) },
  ],
  places: ["PLATE": (810, GUIDE.counterY, 1), "MWIN": (1045, 742, 0.64)],   // 物を置く所 (x, y, 倍率)。GUIDE は横型の配置
  hand: .presenter,                                            // .presenter / .finger / .cursor / .none
  draw: { s in                                                 // 全景 (人物より奥)
    MicrowaveSvg(open: s["mw.open"], on: s["mw.on"], display: s.s("mw.disp"), dish: nil)
  },
  front: { s in                                                // 全景 (人物より手前。運んでいる物など)
    if s.on("dish.vis") { let d = s.obj("dish"); DishWithRice(x: d.x, y: d.y, scale: d.s, heat: s["rice.heat"], wrap: 1) }
  },
  card: { s in }                                               // 拡大カードの中 (袖の腕より奥。画面座標)
)
```

- `CueState`: `s["名前"]`（数。無ければ 0）、`s.s("名前")`（文字）、`s.obj("物")`（位置と倍率。落ちてくる途中の `dy` 込み）、`s.on("名前")`（0.5 より大きい）、`s.num["名前"]`（無いときを区別する）
- **描き方は状態だけから決める**（フレームや時刻を見ない）。動きはキューで付ける。揺れ・湯気など常に動くものは kit の部品（`Steam` `Sparkles` `Drips`）に任せる
- 点は「手を着ける所」の名前にする（`mw.handle` `dish.gripL` `c.knot`）。状態で動く所（開く扉の取っ手、運ぶ物の縁、はがれるラップの結び目）は `s` から計算する。手が着いた後は点に付いていくので、扉を開ける・物を運ぶのに手の動きを書き足さなくてよい
- 道具を手に持たせる（菜箸・スポンジ）: `card` / `front` の中で `s["C.x"]` `s["C.y"]`（`H.x` `H.y`）から持つ所を引いた位置に描く。手がカードの外（`c.away`）にいる間は描かない（カードの端に道具だけが残って見える）
- 画面操作型: `hand: .finger`。画面は `PhoneFrame` の中に `s.s("page")` などで描き分け、点は `PH.pt(設計座標)`。押した見た目は `s.s("pressed") == "save"`
- 手元俯瞰型: `hand: .none`。右手を `H`、左手を `C` にして、`front` で `TopHand(from: topArmFrom(手, .R), to: 手, …)`（左手は `.L`）を描く。手の点 `rest` / `c.away` は画面の下の外（`topOffscreenY()` より下）にし、そこでは描かない。刻む動き: 切った数を値（`cuts=8@時刻`）、包丁の上下を揺れ（`knife.lift=wave 1 .35@時刻`）にし、包丁の位置・押さえる左手の位置は切った数から計算する
- 組み立て説明書型: `hand: .none`。`H` の位置にドライバーの先などの工具を `front` で描く（`Screwdriver(tip:spin:)`）。部品は `IsoBox` を奥から手前の順に描き、組み付けは値（`side.u=0~.8`）で位置をずらす。部品リストはキューの `parts`
- 縦型: 拡大カードは下（`useGuide().layout.closeUp`、y 1235〜1655）。全景の手元はカードの中で見せる。カードを全工程で開いたままにするなら、最初の工程に `card.exit=0`、間の工程に `card.enter=0 card.exit=0`、最後の工程に `card.enter=0`
- 配置の値: 横型は `GUIDE`（天板 `GUIDE.counterY` = 780、床 `GUIDE.counterY + GUIDE.counterH` = 870、拡大カード `GUIDE.closeUp` = x 640〜1600・y 250〜750）、縦型は `LAYOUT_PORTRAIT`（天板 1120、拡大カード x 50〜1030・y 1235〜1655）。`GUIDE` は横型の値なので、縦型の binding では使わない
- 描かない所: 横型では左上の見出し（x 100〜900・y 30〜210）と、y 870 より下（字幕バー）。binding の draw / front の絵がここに重なっても `jgv check` は出さない（check が重なりを見るのは文字・注釈・枠だけ）ので、スナップショットで確かめる
- 物の影: 天板に置いているときだけ `Shadow` を描く（`abs(o.y - 天板の y) < 3`）
- 家具・大型の物（ベッド・冷蔵庫・棚など）はカウンターの上ではなく床（横型 y 870）に立てる。カウンターより手前に描かれ、人物から遠いので、手元は拡大カードで見せる
- 道具の部品（props.swift・SVG）は `CueBinding` の外に関数で書き、binding からは呼ぶだけにする
- `draw` / `front` / `card` の中に `rect` や `path` を直接書くと、輪郭線（`palette.ink`）が付かない。線は `Placed` が付けるので、道具は `Placed` で描く関数にし、画面座標で描く拡大カードの中身は `Placed(x: 0, y: 0) { … }` で囲む

## 拡大カード

```
init <Heat                                    # 開いたまま次の工程へつなぐなら card.exit=0、受ける側は card.enter=0
0.0-.4 card ラップを外す@0.0-.2|ほぐす@0.1-.1
0.0 H>gesture~.4
0.0+.35 C>c.knot~.5;rice.wrap=0@0.1-.4         # 結び目をつまみ、はがし終わるまで付いていく
0.1-.05 C>c.away~.4;tool=1                     # カードの外へ出てから、菜箸に持ち替える
0.1+.35 C>c.rice~.4;C.dx=wave 65 .5@0.2;rice.loose=1@0.2-.1
1.1 shrink bowl.top~.4;H>rest~.4;smile=1~.3;check bowl.badge
```

- カードの中の座標は画面座標（カードの範囲は横型 `GUIDE.closeUp` = x 640〜1600・y 250〜750、縦型 `LAYOUT_PORTRAIT.closeUp` = x 50〜1030・y 1235〜1655）。カードの中の点は `c.` で始める
- 袖の腕の付け根は点 `c.sleeve`（既定はカードの右下の外。binding に書けば変えられる）。手の初めの位置は `c.away`。カードを続ける工程は、前の工程の最後の手の位置から始まる
- 人物はカードの左で指し示す（`H>gesture`）

## jgv check

```
S2 Heat
  ! 5.15-6.31s: 注釈「チン！」 (L8 say) が 字幕バー に重なる
  ! 4: H が mw.handle から 1.23s に離れるが、mw.handle はまだ動いている
  H 0.28-0.73s rest→mw.handle L2
  H 1.23-1.73s mw.handle→mw.start+-10,-16 L4
  start: dish.in=1 mw.open=1 …
  end:   dish.in=0 mw.open=1 mw.disp=0:00 …
S2→S3 ok
```

- `!` の行: 名前の誤り（binding に無い値・点・置き場所・動かせる物。`init` の側も）、存在しない行と句（`@時刻` の側も）、`@時刻` が始まりより前、文字の値に `~秒` / `@時刻` を付けた、人物の型で `C>` を使うのに `card` が無い、縦型で `notes` / `parts` の点が無い、手が遠い（人物の肩から 760px 超）、つまんだ点がまだ動いているのに手を離す（最後に自動で定位置へ戻るときも）、手の動きの重なり（前の動きが着く前に次が動き始める。手は書いた順ではなく着く時刻の順に動く）、同じ値の変化の重なり、終わりの 0.5 秒前より後の動き、右手が定位置に戻っていない
- `?` の行（注意。失敗にはしない）: 指・カーソルが押した後 1 秒より長くそのまま（押し続けて見える）。わざとでなければ、押した後に `H>rest` などで離す
- `! 秒-秒s:` の行（画面の配置）: 工程を 0.25 秒おきに描いて、出そろった文字・注釈・枠の位置から見つける。秒は工程の始まりから。`(L8 say)` は注釈を出したキューの行。Swift の工程でも出る
  - 注釈（吹き出し `say`・チェック `check`・タイマー `timer`）が、ほかの注釈・枠（見出し・工程バッジ・字幕バー・ポイントメモ・部品リスト・小手順ラベル）・binding が描いた文字に重なる
  - 枠が binding の文字に重なる（字幕バーやポイントメモの下に画面の文字が隠れる）
  - 注釈が、後から描く拡大カードに隠れる（全景の注釈をカードの位置に出している）
  - 注釈・枠が画面からはみ出す
  - 直し方は、注釈の点をずらす（`say mw.top+0,-60 …`・`check bowl.badge+40,0`）か、binding の点・置き場所を動かす。出入りの動きの途中（飛び出す・縮んで消える）の一瞬の重なりは出ない。物どうしの重なり・二重に描かれた物は出ないので、画像で確かめる
- `H` / `C` の行: 手の時刻表（何秒〜何秒に、どこからどこへ。`L` はキューの行番号）。読み上げの時刻（`.jgv/timeline.json` の句）と見比べて、動き始めと着く時刻がナレーションに合っているかを確かめる
- `S1→S2`: 前の工程の終わりと次の工程の始まりで違う値。`init <前の工程` で書けばふつう ok。物をカードに持ち込むなど、わざと変えたものだけが出る。`X は片方だけ` は、片方の工程の状態にしか無い値（次の工程の `init` で初めて置いた値など）。`!` の行でなければ誤りではない。拡大カードのつなぎ（前の工程の `card.exit=0` と次の工程の `card.enter=0`）が片方だけなら `!` が出る
- 最後の行は `OK: 問題なし` か `問題 N 件`（`?` があれば `注意 N 件` も付く）。`!` があるとコマンドは失敗で終わる（終了コード 1）

## 確かめ方

1. `jgv check` の `!` が無くなるまで直す（画像を見ずに直せる誤りはここで直す）
2. `jgv dev`（tts → check → 変わった工程だけ snapshots）の `確認する画像:` に出た一覧を Read して、見た目（重なり・大きさ・置き忘れ・二重に描かれた物）を確かめる。句ごとに細かく見るなら `jgv snapshots --phrases`（全体）か `jgv snapshots --scene=N --phrases`（1 工程。出力は `out/snapshots/scene-N/`。全体の `out/snapshots/` は前のまま残るので取り違えない）
3. 直したらまた 1 か 2 から。キューだけを直したときはビルドしないのですぐ終わる。binding（Swift）を直したときはビルドする（1〜数秒）

## Swift で書くとき

キューで書けない動き（値で形が変わる特別な動き）は、binding の描き方の中に Swift で書き、キューから値で動かす（`film=1~.3` で、ラップの膜を手に描くなど）。工程全体を Swift で書く前の書き方（[implementation.md](implementation.md)・[visual-kit.md](visual-kit.md)・[storyboard.md](storyboard.md)・[scene-agent.md](scene-agent.md)）も使える。`visuals/<Visual>.swift` の `CueScene` の 1 行を `func <Visual>(_ props: Props) { … }` の本実装に置き換える（`jgv md2script --stubs visuals --swift-stubs` で Swift の雛形を作る）。キューの工程と Swift の工程は 1 本の動画に混ぜてよい（`jgv check` は Swift の工程を `(swift)` と出す）。
